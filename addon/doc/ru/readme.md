## Возможности дополнения ##

Данное дополнение расширяет функциональность при работе с Microsoft Word:

### Основные функции ###
- **Поиск элементов** (`Win+Alt+F5`) - диалог для вывода списка объектов (комментарии, правки, закладки, поля, концевые сноски, обычные сноски, орфографические/грамматические ошибки и др.)
- **Позиция курсора** (`Alt+Delete`) - озвучивание строки, колонки и страницы позиции курсора или выделенного фрагмента
- **Вставка элементов** (`Win+Alt+F2`) - добавление комментариев, сносок и концевых сносок без перемещения фокуса

### Работа с изменениями ###
- **Правки** (`Win+Alt+M`) - информация о правке в позиции курсора
- **Сноски** (`Win+Alt+N`) - информация о концевой/обычной сноске в позиции курсора

### Навигация ###
- Пропуск пустых абзацев при перемещении (`Ctrl+Стрелки`) (опционально)
- Перемещение между предложениями (`Alt+Стрелки`)
- Специальные команды режима навигации для Word

### Работа с таблицами ###
- Скрипты для перемещения по таблицам и чтения элементов (строки, колонки, ячейки)

### Дополнительные функции ###
- **Информация о документе** (`Win+Alt+F1`)
- Улучшение доступности проверки орфографии (Word 2013/2016):
  - Озвучивание ошибок и предложений (`NVDA+Shift+F7`)
  - Текущее предложение (`NVDA+Ctrl+F7`)
- Автоматическое чтение комментариев, сносок и концевых сносок

## Совместимость ##
Протестировано с Microsoft Word 2019, 2016 и 2013 (возможна работа с Word 365)
